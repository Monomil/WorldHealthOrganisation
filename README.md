# Life Expectancy Predictor

A machine learning project that predicts a population's average life expectancy from country-level statistics, built on the "Life Expectancy (WHO) Fixed" dataset (2,864 rows, years 2000 to 2015).

It ships two ways to interact: a Streamlit web dashboard and a command-line prompt. Both share one prediction function and the same trained models.

## Ethical design

The project deliberately separates features into two consent tiers:

- **Bound tier** uses only non-sensitive statistics: year, region, economic status, GDP per capita, population, and schooling. No health data is required.
- **Unbound tier** adds sensitive public-health data (mortality rates, immunization coverage, HIV incidence, BMI, alcohol consumption, thinness prevalence) for a substantially more accurate prediction.

The unbound model is only used when the user gives explicit, informed consent and supplies every sensitive field. Otherwise the app transparently falls back to the bound model rather than silently degrading or fabricating missing values.

Held-out accuracy is roughly R² = 0.75 for the bound tier and R² = 0.99 for the unbound tier.

## Model selection

Each tier trains four models in the EDA notebook: Linear Regression, Ridge, Lasso, and Random Forest. Random Forest achieves the lowest test error in both tiers, but it overfits more (a larger train-test gap). Linear Regression is selected as the default "best" model for its consistent train/test performance and full interpretability, since every prediction decomposes into signed, quantified feature contributions. The app uses it automatically.

## How the pipeline works

Raw inputs are transformed to match training exactly. Region is one-hot encoded, features are expanded with degree-2 polynomial and interaction terms, scaled with a StandardScaler, then reduced to a fixed stepwise-selected subset. The fitted encoders, scaler, and selectors for each tier are saved in `preprocessing.pkl`, so live inputs are processed identically to the training data (same train/test split, `random_state=42`).

## Project files

- `Life Expectancy Data.csv`: the source dataset.
- `EDA.ipynb`: exploratory analysis, preprocessing, model training, and artifact export.
- `life_expectancy_predictor.py`: the prediction function plus a CLI entry point.
- `app.py`: the Streamlit dashboard.
- `models_bound.pkl` / `models_unbound.pkl`: trained models for each tier.
- `preprocessing.pkl`: fitted preprocessing artifacts and performance metrics.

## How to run

### 1. Set up a virtual environment

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 2. Install dependencies

```powershell
pip install streamlit pandas numpy scikit-learn
```

To run the EDA notebook training, also install the visualization and statistics packages:

```powershell
pip install seaborn matplotlib statsmodels jupyter
```

### 3. Run the Streamlit dashboard

```powershell
streamlit run app.py
```

The dashboard opens in your browser. Answer the consent question, fill in the population statistics, and click **Predict life expectancy**.

### 4. Run the command-line version

```powershell
python life_expectancy_predictor.py
```

This prompts for consent, collects the required statistics, and prints the predicted life expectancy along with the model used and its held-out accuracy.

### 5. Open the EDA notebook (optional)

```powershell
jupyter notebook EDA.ipynb
```

All the `.pkl` files are generated by this notebook, so you only need it to retrain the models or inspect the modeling workflow.
